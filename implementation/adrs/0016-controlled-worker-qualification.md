# ADR 0016: Controlled worker qualification before harness admission

Accepted 2026-11-15. Continues M4 after PR #10 merged into main `55bce1b`. It does not complete M4 or admit a real harness.

Implement an OS-operator-configured Linux qualification adapter with a fixed statically linked trusted payload. Pin Bubblewrap, prlimit and payload digests under immutable active worker policy. Give the payload only synthetic read-only input/policy, a single writable directory, bounded temporary storage and a fresh private namespace environment. No repository code, provider credential, operator DB, host root or arbitrary command is supplied. Measure filesystem restrictions, kernel namespace separation, loopback exclusion, per-process resource limits and known descendant termination. Bound and correlate outputs with a fresh nonce; retain normalized case evidence. Actual kernel observations and host confirmations differ from advertised flags or agent claims.

Before any I/O reserve the attempt, source/worker/case-policy provenance, owner, nonce, deadline and command receipt transactionally. Retries inspect the same attempt. The model-independent supervisor marks overdue attempts interrupted/quarantined and escalates. Late output is unaccepted and cannot restore evidence. Failed metadata finalization cannot silently repeat external work. Quarantine blocks fresh attempts for that case until explicit case-bound operator-reported reconciliation; reconciliation neither grants capabilities nor resolves the underlying duties automatically.

Successful controlled measurements have scope `hermetic-probe-v1` only; `real_execution_admitted` is always false. A TTL/current-policy check is time currency, not live tool/host validation. Fixture-labelled results stay simulated. Private synthetic controller fixtures can exercise success branches but never constitute physical verification. Versioned DTOs, migration 013, CLI/API reporting and a visible web panel preserve audit/recovery continuity.

Observed locally: the direct Bubblewrap namespace test returned `Failed to create NETLINK_ROUTE socket: Operation not permitted`. The product attempt using pinned installed tools and the statically compiled payload returned failed, zero verified capabilities, durable evidence and quarantine/escalation. No restriction was weakened. No successful isolation pass, real model/account/subscription, candidate execution, PR automation, production effect or recovery was verified.

This profile is intentionally narrower than untrusted harness/build execution. It does not prove aggregate/cgroup budgets, fork-bomb containment, general syscall/FD/host-identity defenses, fatal-coordinator loss termination, scoped model-network/authentication or credential revocation. A compatible provisioned worker, additional adversarial drills and actual adapter lifecycle/candidate/regression/review/PR reconciliation remain M4 prerequisites. No unsafe admission override is added.

References: [Bubblewrap authoritative options](https://github.com/containers/bubblewrap/blob/main/bwrap.xml), [prlimit](https://man7.org/linux/man-pages/man1/prlimit.1.html), installed tool help, and the [executable contract](../../contracts/v1/worker-qualification/README.md).
