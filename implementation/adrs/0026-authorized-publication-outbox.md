# ADR 0026: Separately authorized, reconciled publication

Status: implemented with synthetic verification; live activation remains blocked.

Watchhouse owns a publication outbox distinct from model/container execution and merge authority. An OS operator installs immutable, sequential publisher policy with retained installer, canonical source path, digest and installation time. Required configuration names one repository/base, a publisher-only environment credential reference, author identity, draft behavior, pause, wall/request budgets, bounded reconciliation and shared revision limits. No HTTP policy installer or worker dispatcher exists. Harnesses receive neither the publisher credential nor the canonical database/OS authority.

The current owner queues an exact reviewed candidate at an expected aggregate version. It must still satisfy native regression/review, source, knowledge and challenge gates. One stable branch/PR slot belongs to each repair; revisions retain shared candidate deadlines and publication attempt counts. Tree identities come from ADR 0025. Deterministic commit bytes fix author/committer date, message and ordered parents, allowing an unknown commit response to be inspected by its expected Git identity. Revisions descend from the preceding published head and include the frozen base as another parent when different; no force update is authorized.

Each read/write is reserved transactionally with a fence before provider I/O. Every fresh stage checks active policy, pause, owner, exact input bytes/review, deadline and remote base. Branch and PR observations must match their reserved repository/head/base identities. Acknowledgment loss is an owned unknown effect, not permission to send another write. The model-independent supervisor moves unknown/expired in-flight effects into read-only reconciliation. Retry reads are bounded; missing/delayed, foreign, duplicate or inconsistent observations quarantine the effect. A published PR that has become stale is retained as such, never promoted to current merge authority. An OS operator can request another scoped inspection, which does not reset the automatic retry budget or grant write replay.

PR discovery requests all states for the exact head/base with a bounded page. Zero or one result is complete; multiple or saturated results fail closed. Existing closed/foreign PRs cannot cause silent replacement. Updates use the same known PR number. Failed/uncertain publications remain unresolved and block later revisions until exact effects can be reconciled. No blind abandonment/reset command is supplied.

The wire adapter uses the fixed GitHub Cloud origin, a pinned API version, redirect/proxy denial, bounded request/response sizes and timeouts, sanitized errors, scoped branch updates and a small endpoint allowlist. It has no merge/delete endpoint. Native HTTP observations and synthetic fixtures have distinct provenance. CLI/API/UI share enqueue/status behavior; incident snapshots expose bounded summaries without credentials, internal fences or write bodies. Publication does not establish merge, deployment or recovery.

Fixtures cover every lost write acknowledgment, duplicate/delayed PR visibility, reuse of branch/PR across revisions, shared deadlines, pause/stale-file/base/credential denial, coordinator-loss reconciliation, atomic rollback, concurrent idempotency and inert browser rendering. Actual benign Git independently verifies deterministic commit identities including ordered parents/newlines. These are not live GitHub or model proof. Live acceptance requires a dedicated authorized test repository and separately scoped publisher credential; the coding assistant's PR publication is not that test.
