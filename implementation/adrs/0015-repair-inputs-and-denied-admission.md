# ADR 0015: Frozen repair inputs before real worker admission

Accepted 2026-11-15. First M4 preparation slice, after PR #9 merged into main `b15361d`. It does not complete M4.

M2's database fences are safe for side-effect-free fake workers, not for a subprocess that can mutate files or retain credentials. Start M4 with an OS-operator-only immutable repair-source configuration, object-only snapshot preparation, installed-runtime metadata and a durable denied-admission path. Expose preparation and owned blockers through CLI/API/web, preserving the separate fake workflow. No real runner registration or configurable bypass is added.

Read full-commit Git objects with bounded fixed argument arrays, clean environment, no lazy fetch/replacement refs and no checkout/filter/hook execution. Reject symlinks/gitlinks, unsafe/case-colliding paths and oversized inputs. Independently verify SHA-1/SHA-256 Git blob identities; use SHA-256 manifests for frozen evidence. Create a private copy without `.git`; never describe a copy or read-only permissions as isolation. Pin runtime binary digest and inspect only version/help with clean home/config and bounded output/deadline. Keep advertised flags distinct from verified capabilities. Installed Git and the pinned executable are operator-trusted tools, not adversarial code admitted by this mechanism.

An exact-version, evidence-backed operator request freezes base/tree/config/manifest/case-policy provenance and the expected behavior/regression proposal. Require exact source repository/deployed-revision mapping where a source exists. Recheck integrity without holding the canonical writer lock; commit the blocked request, event, escalation and command receipt atomically. New configurations never mutate prior requests or waive their duties. Model absence cannot disable the existing escalation supervisor.

Actual local observation: codex-cli 0.167.0-alpha.4 version/help succeeded with `--json`, `--output-schema`, `--ignore-user-config`, `--ignore-rules` and `--ephemeral` advertised. No model/account/subscription was invoked or probed. A local Bubblewrap qualification attempt failed with `Failed to create NETLINK_ROUTE socket: Operation not permitted`. That is not evidence of qualified containment. `verified` capabilities therefore remain empty and real admission remains denied on every platform. No successful containment drill is claimed from CLI flags, a prompt or a successful file copy.

Standard tests use synthetic local Git repositories, fake execution and harmless Git version output as an unrecognized runtime. They cover byte/identity pinning, private/untracked exclusion, unsafe modes/paths, bounds, clean environment and probe deadlines, policy/config immutability, mapped-base denial, stale/foreign commands, concurrency, rollback, restart, escalation and browser replay. Opt-in local metadata preparation froze 135 files / 2,093,570 bytes at the merged M3 tree; this proves preparation only.

Remaining M4: qualified OS/container/worker boundary, cancellation/revocation and reconciliation, real Codex protocol adapter, bounded engineer/verifier/reviewer loops, candidate/regression validation and PR delivery/reconciliation. Temporary-copy quarantine/cleanup, directory sealing and robust crash recovery must precede any execution authority. M3 actual-history/live activation, M5 recovery and M6 automatic merge remain separate.

References: installed version/help observed locally; [Git global controls](https://git-scm.com/docs/git), [Git object format](https://git-scm.com/book/en/v2/Git-Internals-Git-Objects), and ADR 0004. The executable [repair contract](../../contracts/v1/repair/README.md) defines current limits.
